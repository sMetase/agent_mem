# 智能体记忆系统前端使用说明

> 说明：本文档面向演示和测试人员，描述如何使用当前前端页面完成一次完整演示。

## 1. 打开系统

本地运行时，浏览器访问：


```text
http://120.27.207.238:8002
```

如果页面能打开但接口不可用，需要先进入“系统设置”检查后端 Base URL。

## 2. 首次配置

打开左侧菜单：

```text
7. 系统设置
```

建议先配置：

- Base URL：后端服务地址，例如 `http://120.27.207.238:8000`。
- User ID：当前测试用户，例如 `test_user_001`。
- Scene ID：当前测试场景，例如 `scene_demo_001`。
- Agent ID：当前智能体，例如 `agent_demo_001`。
- API Key：如果后端要求鉴权，则填写；如果当前没有鉴权要求，可以留空。

保存后，后续页面会自动使用这些配置请求后端。

## 3. 检查接口是否可用

打开左侧菜单：

```text
6. 接口与监控 → 接口健康检查
```

点击“刷新数据”。

正常情况：

- 后端服务显示正常。
- 能看到应用名称、版本或状态。
- 耗时有具体数值。

如果显示“状态未知”或“后端返回非健康状态”，说明页面已打开，但健康检查接口没有被正确识别。需要检查 Base URL、后端 `/health` 返回格式或 nginx 代理配置。

## 4. 导入记忆

打开左侧菜单：

```text
1. 智能体接入与记忆数据写入 → 记忆数据导入
```

可以选择三种导入方式：

- 对话记录：导入用户与智能体之间的历史对话。
- 历史会话：导入已经结束的会话摘要。
- 任务过程：导入任务目标、进展、结果等信息。

常用测试方式：

1. 选择“对话记录”。
2. 填写一条用户内容，例如“晨星物流项目使用 React、Vite 和 TypeScript 开发前端。”
3. 点击写入或导入。
4. 页面提示写入成功后，进入记忆管理页查看。

如果使用 JSON 文件导入，需要保证字段与当前导入模式匹配。

对话记录示例：

```json
[
  {
    "role": "user",
    "content": "晨星物流项目使用 React、Vite 和 TypeScript 开发前端。",
    "scene_id": "scene_logistics",
    "task_id": "task_frontend_demo"
  }
]
```

历史会话示例：

```json
[
  {
    "session_summary": "讨论了冷链配送系统的高峰时段调度策略。",
    "session_time": "2026-07-16T10:00:00Z",
    "session_source": "demo_import",
    "scene_id": "scene_logistics",
    "task_id": "task_dispatch"
  }
]
```

任务过程示例：

```json
[
  {
    "task_goal": "完成物流调度看板前端页面。",
    "task_progress": "已完成记忆导入、检索和上下文返回页面。",
    "task_result": "进入联调和演示准备阶段。",
    "scene_id": "scene_logistics",
    "task_id": "task_frontend_demo"
  }
]
```

## 5. 查看和管理记忆

打开左侧菜单：

```text
2. 通用记忆建模与多层记忆管理
```

可以进入：

- 用户级记忆。
- 会话级记忆。
- 任务级记忆。
- 智能体级记忆。

常用操作：

- 点击刷新，加载后端记忆列表。
- 使用筛选条件缩小范围。
- 查看记忆内容、类型、标签、状态、重要性和置信度。
- 编辑单条记忆。
- 清除记忆。

清除记忆操作：

1. 点击右上角“清除记忆”。
2. 记忆列表前方会出现选择框。
3. 勾选需要删除的记忆。
4. 底部可以点击“全部选中”。
5. 再次点击可取消全选。
6. 点击“清除所选记忆”。
7. 删除后刷新列表确认结果。

## 6. 生成与去重融合

打开左侧菜单：

```text
3. 记忆生成与去重融合
```

该模块用于演示后端如何从原始文本中提取结构化记忆，并完成去重、融合等处理。

可演示的子功能包括：

- 用户偏好提取。
- 关键事实提取。
- 任务状态生成。
- 历史决策沉淀。
- 冲突检测。
- 冲突记忆去重。
- 相似记忆去重。
- 记忆融合管理。
- 低价值内容过滤。

演示流程：

1. 选择一个子功能。
2. 输入一段包含业务信息的文本。
3. 点击生成。
4. 查看生成结果、事件类型和处理明细。
5. 如果是批量测试，可导入多条文本进行批量生成。

## 7. 记忆检索

打开左侧菜单：

```text
4. 多信号融合记忆检索
```

推荐演示入口：

- 语义向量检索。
- 关键词检索。
- 元数据过滤。
- 融合排序。
- Top-K 返回。

演示流程：

1. 输入问题，例如“晨星物流项目使用什么技术栈？”
2. 设置 Top-K 数量，例如 5。
3. 根据需要选择记忆类型或状态。
4. 点击检索。
5. 查看结果列表、候选数和耗时。

如果刚导入的数据检索不到，可以先确认：

- 是否导入成功。
- User ID 是否一致。
- Scene ID 或 Task ID 是否限制过严。
- 后端是否已经完成记忆生成和索引入库。

## 8. 上下文返回

打开左侧菜单：

```text
5. 记忆上下文返回
```

可演示：

- 结构化 JSON 返回。
- 文本上下文片段返回。
- 相关性筛选。
- 长度控制与压缩。

演示流程：

1. 输入当前任务或问题。
2. 设置用户、场景、任务等条件。
3. 设置最大长度或返回数量。
4. 点击生成上下文。
5. 查看返回的 JSON 或文本片段。

该模块用于展示“系统如何把历史记忆整理成可注入智能体的上下文”。

## 9. 任务过程管理

打开左侧菜单：

```text
任务过程管理
```

可进行：

- 创建任务。
- 查询任务进度。
- 更新任务进度。
- 维护已完成项和待办项。

建议演示时使用固定 Task ID，便于后续在记忆导入、检索和上下文返回中关联同一任务。

## 10. 接口监控和联调记录

打开左侧菜单：

```text
6. 接口与监控
```

可查看：

- 接口健康检查。
- 调用状态监控。
- 联调记录。

该模块适合给老师说明系统不是纯静态页面，而是已经与后端接口发生真实交互。

如果某些接口显示异常，可以解释为：

- 前端页面已完成入口和调用逻辑。
- 当前后端接口可能仍在联调。
- 部分管理接口或统计接口需要后端继续补齐。

## 11. 推荐演示顺序

建议按照下面顺序演示：

1. 打开系统总览，介绍系统整体能力。
2. 进入系统设置，说明当前连接的后端地址和测试用户。
3. 进入接口健康检查，证明前后端已连通。
4. 进入记忆数据导入，导入一条或一批测试数据。
5. 进入用户级记忆或智能体级记忆，刷新并查看导入结果。
6. 进入记忆生成与去重融合，演示结构化记忆生成过程。
7. 进入多信号融合记忆检索，输入问题并展示检索结果。
8. 进入记忆上下文返回，展示系统如何生成上下文。
9. 进入接口监控，展示调用状态和联调情况。

## 12. 演示时可以这样介绍

可以使用下面这段话概括系统：

```text
这个前端不是一个普通聊天页面，而是一个面向智能体记忆管理的控制台。
它支持把历史对话、历史会话和任务过程导入系统，通过后端接口生成结构化记忆，
再进行记忆管理、检索、去重融合和上下文返回。
后续智能体执行任务时，可以从这里检索相关历史经验和用户偏好，
作为任务推理和响应生成的上下文支撑。
```

## 13. 注意事项

- 前端页面运行正常不代表所有后端接口都已经稳定。
- 如果健康检查失败，优先检查 Base URL、nginx 转发和 `/health` 返回格式。
- 如果导入成功但列表看不到，优先检查 User ID、Scene ID、Task ID 是否一致。
- 如果检索不到结果，可能是后端索引、生成或检索策略还未完成。
- 如果线上使用 HTTPS，后端接口也应通过 HTTPS 或同域 nginx 代理访问。
