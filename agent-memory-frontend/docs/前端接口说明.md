# 智能体记忆系统 — 前端接口对接文档

> 版本：v1.0 | 更新日期：2026-07-06

---

## 一、系统说明

### 1.1 系统功能

用户和AI对话时，系统自动提取有价值的记忆（偏好、事实、任务状态）并存储。下次对话时AI检索这些记忆，实现连续个性化对话。

**核心流程：**

用户说话 → 检索历史记忆 → AI回复 → 存入本次对话记忆

### 1.2 前端职责

| 职责 | 说明 |
|------|------|
| 智能体注册 | 应用首次启动获取 `api_key` |
| 会话管理 | 创建/关闭对话会话 |
| 记忆写入 | 每轮对话后存储对话内容 |
| 记忆检索 | 每次用户发问题前获取历史记忆 |
| 记忆管理 | 查看/删除/更新记忆 |
| 任务追踪（可选） | 长周期任务进展管理 |

```

字段	    说明

三、接口详情
3.1 注册智能体
接口： POST /api/v1/agent/register

说明： 每个前端应用首次启动时调用一次，获取 api_key。密钥仅返回一次明文，需保存到本地存储。

请求参数：

字段	类型	必填	说明
agent_name	string	是	智能体名称
scene_id	string	是	场景标识
permissions	array	是	权限列表，如 ["read","write"]

请求示例
{
  "agent_name": "Web聊天助手",
  "scene_id": "chat",
  "permissions": ["read", "write"]
}
响应示例
{
  "code": 0,
  "data": {
    "agent_id": "agent_abc",
    "api_key": "mem_xxxx",
    "api_key_prefix": "mem_****"
  }
}

返回字段	说明
agent_id	智能体ID
api_key	接口密钥（仅返回一次，请立即保存）
api_key_prefix	密钥前缀（仅用于前端显示）

3.2 创建会话
接口： POST /api/v1/session

说明： 用户开始新对话时调用。

请求参数：
字段	类型	必填	说明
user_id	string	是	用户唯一标识
agent_id	string	是	智能体ID（从注册接口获取）
scene_id	string	否	场景标识
task_id	string	否	任务ID（如有）
请求示例：

{
  "user_id": "user_001",
  "agent_id": "agent_abc",
  "scene_id": "chat"
}
相应示例：
{
  "code": 0,
  "data": {
    "session_id": "sess_abc",
    "status": "active"
  }
}

3.3 写入记忆
接口： POST /api/v1/memory/write

说明： 每轮对话后调用，将对话内容写入系统，自动提取记忆。

请求参数：

字段	类型	必填	说明
user_id	string	是	用户唯一标识
scene_id	string	否	场景标识
task_id	string	否	任务标识
session_id	string	否	会话ID
messages	array	是	对话消息列表
messages 格式：

[
  {"role": "user", "content": "用户输入内容"},
  {"role": "assistant", "content": "AI回复内容"},
  {"role": "system", "content": "系统消息"}
]
role 可选值：user / assistant / system

请求示例：

{
  "user_id": "user_001",
  "scene_id": "chat",
  "session_id": "sess_abc",
  "messages": [
    {"role": "user", "content": "我叫张伟，喜欢Python后端开发"},
    {"role": "assistant", "content": "好的，我记住了你的偏好"}
  ]
}
响应示例：

{
  "code": 0,
  "data": {
    "results": [
      {
        "id": "mem_abc",
        "memory": "用户名为张伟，偏好Python后端",
        "event": "ADD"
      }
    ]
  }
}
返回字段	说明
id	记忆ID
memory	提取的记忆内容
event	ADD（新增）/ SKIP（跳过）/ MERGE（合并到已有记忆）
3.4 检索记忆
接口： POST /api/v1/memory/search

说明： 用户每次发起新问题时调用，检索相关历史记忆。检索结果应注入AI Prompt。

请求参数：

字段	类型	必填	说明
query	string	是	搜索文本（用户当前问题）
user_id	string	是	用户唯一标识
scene_id	string	否	只查该场景下的记忆
task_id	string	否	只查该任务相关的记忆
memory_types	array	否	类型过滤，可选值见「记忆类型枚举」
time_start	string	否	开始时间，ISO 8601格式
time_end	string	否	结束时间，ISO 8601格式
top_k	int	否	返回条数，默认10，最多50
rerank	bool	否	是否启用二次排序，开启更准但更慢
请求示例：

{
  "query": "后端技术栈",
  "user_id": "user_001",
  "scene_id": "chat",
  "memory_types": ["preference"],
  "top_k": 5
}
响应示例：

{
  "code": 0,
  "data": {
    "query": "后端技术栈",
    "results": [
      {
        "memory_id": "mem_abc",
        "content": "用户使用Python和FastAPI",
        "relevance_score": 0.853,
        "memory_type": "preference",
        "scene_id": "chat",
        "task_id": "task_001",
        "created_at": "2026-07-06T10:30:00Z"
      }
    ],
    "total_candidates": 12,
    "elapsed_ms": 156
  }
}
返回字段	说明
results	检索结果列表
memory_id	记忆ID
content	记忆内容
relevance_score	相关性分数（0-1），越高越相关
memory_type	记忆类型
total_candidates	总候选数
elapsed_ms	检索耗时（毫秒）

5.1 前端请求方式
基础配置：

const BASE_URL = 'http://<后端IP>:8000';

// 从本地存储获取 api_key（注册接口返回后保存）
const API_KEY = localStorage.getItem('api_key');

const headers = {
  'Content-Type': 'application/json',
  'X-API-Key': API_KEY  // 未来启用
};
通用请求方法：

javascript
async function request(endpoint, method = 'POST', body = null) {
  const options = {
    method,
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': localStorage.getItem('api_key')
    }
  };
  
  if (body) {
    options.body = JSON.stringify(body);
  }
  
  const response = await fetch(`${BASE_URL}${endpoint}`, options);
  const result = await response.json();
  
  if (result.code === 0) {
    return result.data;
  } else {
    // 失败处理
    console.error('接口错误:', result.message, result.error_code);
    throw new Error(result.message);
  }
}

5.3 完整对话流程
// 1. 创建会话
const session = await request('/api/v1/session', 'POST', {
  user_id: 'user_001',
  agent_id: 'agent_abc',
  scene_id: 'chat'
});
const sessionId = session.session_id;

// 2. 发送消息
async function sendMessage(userInput) {
  try {
    // 2.1 检索历史记忆
    const searchResult = await request('/api/v1/memory/search', 'POST', {
      query: userInput,
      user_id: 'user_001',
      top_k: 5
    });
    
    // 2.2 生成AI回复（注入记忆）
    const context = searchResult.results.map(m => m.content).join('\n');
    const aiReply = await callYourAI(context, userInput);
    
    // 2.3 写入记忆
    await request('/api/v1/memory/write', 'POST', {
      user_id: 'user_001',
      session_id: sessionId,
      messages: [
        { role: 'user', content: userInput },
        { role: 'assistant', content: aiReply }
      ]
    });
    
    return aiReply;
  } catch (error) {
    // 降级处理
    console.error('对话异常:', error);
    return await callYourAI(null, userInput);  // 无记忆继续对话
  }
}

// 3. 关闭会话
await request(`/api/v1/session/${sessionId}/close`, 'POST');
