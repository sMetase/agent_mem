## 一、前端功能全景（各大模块与子模块）

整体是一个面向多智能体的**记忆管理中台**，覆盖"智能体接入 → 记忆写入 → 多层管理 → 生成融合 → 检索 → 上下文返回 → 运行监控"的完整链路。侧边栏共 **7 大分区、30+ 页面**，另有首页总览、任务过程管理与登录体系。

| 大模块 | 子模块 | 功能说明 |
| --- | --- | --- |
| **1. 智能体接入与记忆数据写入** | 智能体注册接入 | 注册业务智能体并保存身份凭据；接入已有智能体，按平台（Dify/Open WebUI/阿里云 IMS/智谱）动态切换字段 |
| | 场景标识配置 | 创建业务场景，隔离智能体、任务与记忆数据 |
| | 接口密钥配置 | 维护 Agent ID 与 API Key（支持轮换） |
| | 记忆数据导入 | JSON/CSV 导入对话、会话摘要与任务过程；强制关联 Agent ID |
| | 数据校验与标准化 | 校验导入文件结构并预览标准化结果 |
| **2. 多层记忆管理** | 用户级记忆 | 用户偏好、稳定事实、长期约束 |
| | 会话级记忆 | 按会话查看历史摘要与上下文 |
| | 任务级记忆 | 按任务管理目标、进展与执行结果 |
| | 智能体级记忆 | 智能体名下全部记忆 |
| **3. 记忆生成与去重融合** | 用户偏好提取 / 关键事实提取 / 关键实体人物生成 | 3 个分析类预设：选记忆 → 执行分析 → 差异化结果 |
| | 任务状态生成 / 历史决策沉淀 / 冲突检测 / 冲突记忆去重 / 相似记忆去重 / 记忆融合管理 / 低价值内容过滤 | 7 个文本类预设：结果形态各自差异化 |
| **4. 多信号融合记忆检索** | 语义向量检索 / 关键词检索 / 元数据过滤 / 融合排序 / Top-K 返回 | 5 种子模式 + 综合视图，结果区各不同 |
| **5. 记忆上下文返回** | 结构化 JSON / 文本上下文片段 / 相关性筛选 / 长度控制与压缩 | 4 种返回形式 + 综合视图 |
| **6. 接口与监控** | 接口健康检查 / 调用状态监控 / 联调记录 | 服务连通性、接口状态、告警与联调记录 |
| **7. 系统设置** | 基础连接设置 / 本地用户身份 | 后端连接地址、联调用 User ID |
| **首页总览（非菜单）** | 实时监控看板 + 系统总览 | 接口调用频次/成功率、健康状态、请求路径统计、失败追溯 |
| **任务过程管理（非菜单）** | 创建任务、维护进度 | 关联任务过程记忆 |
| **登录体系（非菜单）** | 登录 / 注册 / 密码找回 / 个人中心 | 登录守卫 + mock 认证 + GitHub OAuth2 占位 |

## 三、0813 追加：界面差异化改造（解决"模板化、样式雷同"）

老师指出"生成/检索/上下文三个模块的子功能界面高度同质化"——统一前置流程（选记忆→勾选→分析）属于规范，保留；需要差异化的是**结果展示区**。我们已全部落地：

**「3. 记忆生成与去重融合」7 个文本预设，结果形态各不相同：**

| 预设 | 差异化结果形态 |
| --- | --- |
| 用户偏好提取 | 用户画像标签墙 + 多维度雷达图 + 维度明细表 |
| 关键事实提取 | 事实条目卡片流 + 事实关联树 |
| 关键实体人物生成 | 实体人物卡片网格（人物/组织/产品分型着色） |
| 任务状态生成 | 任务进展时间线（阶段标记 + 状态徽章 + 进度条） |
| 历史决策沉淀 | 决策卡片（决策/依据/适用条件/结论分块） |
| 冲突检测 | 新旧记忆左右对比视图 + 冲突高亮 |
| 冲突记忆去重 | 冲突清单 + 解决状态标签 |
| 相似记忆去重 | 相似分组卡片 |
| 记忆融合管理 | 融合前后对照（来源 → 结果，箭头流转） |
| 低价值内容过滤 | 灰色丢弃清单 + 丢弃原因标签 |

**「4. 多信号融合检索」6 模式：** 语义=相关度排序列表、关键词=命中高亮、元数据=左侧筛选面板+右侧清单、融合排序=四信号权重条、Top-K=截断条、全部=综合仪表盘。

**「5. 记忆上下文返回」5 模式：** JSON=结构树、文本=可注入文本卡片、相关性=分级列表、长度=Token 预算条+压缩对比、全部=综合视图。

> 合计约 18 种结果形态，全部基于现有接口返回结构做纯前端渲染层差异化，不改后端。
