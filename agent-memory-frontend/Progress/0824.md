## 一、记忆画像模块（重点改造）

### 1.1 数据结构契约（前端定义，后端后续填充）

当前 `POST /memory/profile` 返回 `{persona, scene_id, changed_scenes}`。前端扩展 `MemoryProfileResult`，新增 `visual` / `stats` 字段（后端未返回时用演示数据兜底 + 「演示数据」橙色标注，沿用项目惯例）：

```ts
interface ProfileVisualData {
  radar: Array<{ dimension: string; score: number }>      // 雷达图维度（如 专业能力/沟通/决策/协作/效率 等，0-100）
  memoryTypeDist: Array<{ type: string; count: number }>   // 5 类记忆分布
  tags: string[]                                           // 高频关键词/标签
  trend: Array<{ date: string; count: number }>            // 记忆随时间分布
}
// MemoryProfileResult 扩展：
// visual?: ProfileVisualData
// stats?: { total_memories: number; active_memories: number }
```

### 1.2 可视化展示（图文并茂，告别纯文本）

画像页重构为「看板式」布局：
- **顶部**：用户基础信息（userId / 所属场景 / 变更场景数）+ 画像总结文字（persona）
- **中部**：雷达图（维度得分）+ 记忆类型分布（Pie/Column 二选一，5 类新枚举）
- **底部**：记忆时间趋势（Line）+ 高频标签（Tag 云）
- 图表用 `@ant-design/plots`（Radar / Pie / Column / Line，复用现有依赖，不新增库）

### 1.3 三套展示模板

顶部 Segmented 切换，同一份数据渲染不同布局，选择存 localStorage：

| 模板 | 风格 | 适用 |
|---|---|---|
| **数据看板** | 图表为主，雷达+分布+趋势全量展示 | 大屏/演示 |
| **极简卡片** | 克制的文字+标签+数字统计，弱化图表 | 快速浏览 |
| **报告式** | 标题+摘要+图表+总结的图文混排 | 导出/打印/汇报 |

### 1.4 画像报告导出（打印 PDF，零新依赖）

- 画像页顶部新增「导出报告」按钮 → `window.print()`（浏览器打印，可另存为 PDF）。
- 新增打印样式（`@media print`）：隐藏页面导航/按钮/模板切换，仅保留报告区域；打印时自动采用「报告式」模板布局。
- 报告内容：**用户基础信息 + 记忆条数统计 + 画像文字总结 + 可视化图表**（与任务要求一致）。

## 二、记忆数据导入：新增远程 API 通道

### 2.1 双导入方式兼容

导入页「历史会话批量导入」区域顶部新增 Segmented：**「文件导入」/「远程 API 导入」**。
- 文件导入 = 现有批量/文件夹导入，原样保留。
- 远程 API 导入 = 新增面板（见 2.3）。

### 2.2 外部接入源管理（新页面/模块）

新增菜单「外部数据源管理」（接入区块下）。管理多条接入源，**配置存 localStorage**（新 key，后端对接前）：

| 功能 | 说明 |
|---|---|
| 接入源列表（表格） | 名称、类型（Open-Web-UI / 外部智能体）、接入地址、状态（启用/停用）、最近拉取时间、上次结果 |
| 新增 / 编辑 | 名称、类型、接入地址、API-Key（密码框）、可选附加参数 |
| 启用 / 停用开关 | 控制是否参与拉取（定时拉取真实调度需后端 worker，见 2.2-注意） |
| 立即拉取并导入 | 前端 fetch 接入源 → 复用 OpenWebUI 清洗器 → 预览 → 写入 `/memory/write` |

**注意（前端限制，需后端）**：
- **定时拉取**：纯前端页面关闭即失效，无法可靠定时 → 启停开关作为配置状态保存，真实定时调度列入后端改造清单。
- **跨域（CORS）**：前端直连外部 API 受浏览器同源策略限制；若外部服务不支持 CORS 则拉取失败并提示。长期方案 = 后端代拉（见后端改造清单）。

### 2.3 远程 API 导入面板 UI

远程面板 = 接入源下拉（读取 2.2 数据）+「立即拉取并导入」按钮 + 拉取结果预览（清洗后的会话数 / 失败提示）→ 确认后走现有 write 链路。

## 三、系统设置：新增大模型服务配置

### 3.1 功能

Settings 页在「后端服务连接」卡片下方新增 **「大模型服务配置」** 卡片：

- 多条配置表格：名称、类型（DeepSeek / OpenAI 兼容 / 自定义）、接口地址（Base URL）、状态（启用/停用）
- 支持新增 / 编辑 / 删除；每条**独立启停**开关
- 字段：名称、类型、接口地址、API-Key（密码框）、可选 model 名称
- 存 localStorage（新 key），标注「配置保存在当前浏览器；后端接入后由服务端读取生效（见后端改造清单）」

### 3.2 与现有配置的关系

- 保持「后端服务连接」（baseUrl）不动；大模型配置独立成板块、独立启停，不写死单一模型。
- 扩展 `AppConfig`？**不扩展**——大模型配置与连接配置解耦，用独立 storageKey + 独立类型，避免污染既有配置流。
- **执行调整（2026-08-24）**：合并远程提交后确认后端已实现 `/api/v1/config/llm`（全局默认 + 智能体级配置，AgentAccess 支持按智能体配置）。经确认**采用远程「全局默认 LLM 配置」**，本方案的本地 `LLMConfigPanel`（localStorage 多条配置）不再实施，避免设置页重复。
