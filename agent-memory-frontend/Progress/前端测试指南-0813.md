## 九、已知后端限制（造数/测试中发现，非前端问题，需向后端反馈）

1. **`embedding_client.py` 缺 `import json`**：`_call_api` 的异常处理里引用 `json` 但未导入，导致 embedding 调用必然抛 `NameError`。影响：检索永远降级、上下文接口直接失败。
   - 定位：`memProject/app/services/embedding_client.py` 顶部补 `import json` 即可（一处小改动，本地联调建议直接改，正式环境请后端李国庆修复）。
2. **`/memory/context` 无降级兜底**：embedding 失败时直接返回 `CONTEXT_FAILED`，前端上下文 5 个模式的差异化结果看不到。需后端加 DB-only 兜底（或填 Key）。
3. **检索降级只扫最近 `top_k×2` 条**：`memory_store._db_only_search` 先取最近 top_k×2 条再做关键词匹配。测试时把「返回数量」调到 20/50 即可覆盖全部记忆。
4. **`/memory/write`、`/memory/generate` 无 Key 时不出记忆**：导入/文本生成会失败或返回 SKIP，属预期。
5. **任务级「已完成任务数」恒为 0**：前端统计口径问题（归档记忆不进列表），建议在 8/28 前与老师确认口径。
